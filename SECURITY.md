# Security policy

## Supported versions

Only the latest release receives security fixes. Dev pre-releases are replaced
by the next one and are not patched on their own.

## Reporting a vulnerability

Please report security problems privately through GitHub:
[Report a vulnerability](https://github.com/Rdiger-36/HaspelSync/security/advisories/new)
(Security tab of this repository). Do not open a public issue for them.

A useful report includes:

- the affected version or image tag
- the affected file, route or setting
- how to reproduce it, and what an attacker gains

Reports that only point to a third-party dashboard or ask for a login
elsewhere are closed without reply. The details belong in the report itself.

This is a hobby project maintained in spare time. You will usually get a first
answer within a few days.

## Scope

HaspelSync is meant to run in a trusted local network next to the printer and
Spoolman. Findings about the printer firmware, Bambu Lab cloud services or
Spoolman itself belong with those projects.
